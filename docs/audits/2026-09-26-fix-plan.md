## 每批问题清单

### B1 信号算法核心（Fable）
1. [P0-1] 衰减封顶与阈值联动：`cap = max(20, eff_last − lockThreshold + 6)` 或衰减向阈值逼近
2. [P0-6] lockTimeout 插值方向：`t = (slope + fastSlopeThreshold) / (mildSlopeThreshold − fastSlopeThreshold)`
3. [P1] Kalman 负向 delta 加速 Q（带 anomaly/slope 门控）
4. [P1] Q 按 dt 缩放（`Q_step = Q_base × dt`，dt 钳制 ≤5s）
5. [P1] EWLR 窗口 ≥ 2×最大采样间隔（4s）
6. [P1] IQR：窗口按最近固定 N 样本（≥5 可达），异常样本跳过更新或降权
7. [P1] 衰减惩罚仅对下降方向放大（slope>0 减免）
8. [P1] 衰减独立于采样间隔（对 elapsed 封顶 2s 或按速率建模）
9. [P2] heartbeat 哨兵缺陷（lockRSSI=-100 时 3s 档、禁锁后停止空转）
10. [P2] 心跳读数与采样路径衰减一致性（统一 decayedEffectiveRSSI）
11. [P2] RingBuffer 容量（300→600，覆盖 0.5s 档 5 分钟）
12. [P2] 信号中断后 Kalman 重置（elapsed > N 秒时 P 膨胀）
验证：`xcodebuild test -project FUnlock.xcodeproj -scheme FUnlock`（SignalPipeline/StateMachine 相关用例全绿）

### B2 阈值联动与钳制（Sonnet）
1. setUnlockRSSI 联动保证 `lock < unlock`（消除 -100/-95 反向迟滞循环锁屏）
2. lock 滑块提交时钳制 `lock ≤ unlock − gap`（OverviewView/Debug 提示）
3. 阈值钳制单一来源：RSSIRange 下沉 SignalHysteresisEngine，4 处重复收敛
4. CalibrationWizardView 迟滞 5→10（用 lockUnlockDelayGap）
5. CalibrationWizardView 采样源改 effectiveRSSI
6. thresholdRSSI 过滤与 unlock=-100 矛盾（-95 语义边界对齐/文档化）
7. 配置导入合理性校验：clamp 到 UI 范围 + unlock 严于 lock（ConfigStore.importAllSettings / ProfileManager.importFrom）
8. importAllSettings 的 keysToRemove 加 knownKeys 过滤（防删任意 key）
9. unlockRSSI=1 时 presence 翻转仍记假 unlocked 事件（checkProximity 哨兵短路）
10. preWake/stair 在 unlockRSSI=1 时的外推修正（-120 外推钳制）
验证：xcodebuild test + 手动边界用例（-100 联动、导入非法配置）

### B3 解锁门控与状态机（Sonnet）

## 执行纪律

- 每个子智能体：只改本批清单内的问题，不顺手改别的；匹配现有代码风格；改完自己跑测试。
- 主会话：每批完成后 review diff、跑全量测试、确认无回归再进下一批。
- 全部批次完成后：全量测试 + 打包冒烟（遵循安装流程 memory：先删再装、pkill 确认退出）。
- 不做 git commit（除非用户要求）；所有改动留在工作区，用户可随时 review diff。
