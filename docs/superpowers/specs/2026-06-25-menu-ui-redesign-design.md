# FUnlock 菜单栏弹窗 UI 重构设计文档

**日期**: 2026-06-25
**版本**: v1.0
**状态**: 已确认

## 概述

将 FUnlock macOS 菜单栏弹窗从当前扁平布局重构为侧边栏导航 + 卡片式设置分组 + 苹果玻璃风格（vibrancy），提升空间利用率和视觉品质。

## 设计决策

### 布局结构

```
┌─ 设备状态栏（固定顶部）─────────────────────┐
│  ● iPhone 14 Pro Max   设备已解锁   [解绑]   │
├──────────┬──────────────────────────────────┤
│  侧边栏  │  内容区（可滚动）                  │
│  (140px) │                                  │
│          │  根据选中 tab 切换显示内容          │
│  总览    │                                  │
│  设备    │                                  │
│  基础    │                                  │
│  解锁    │                                  │
│  锁定    │                                  │
│  网络    │                                  │
│  配置    │                                  │
├──────────┴──────────────────────────────────┤
│  [🔒 立即锁定]              [⏻ 退出]        │  ← 固定底部
└─────────────────────────────────────────────┘
```

### 弹窗尺寸
- 宽度: 440px
- 高度: 内容自适应，固定 440px 可滚动区域
- 侧边栏宽度: 140px

### 视觉风格
- 背景: `NSVisualEffectView` 磨砂玻璃效果（sidebar material + 混合模式）
- 圆角: 14px
- 阴影: macOS 标准 popover 阴影
- 字体: SF Pro Text，13px 正文，17px 标题
- 色值: Apple 标准色板（#007aff, #30d158, #ff375f, #ff9f0a 等）
- Toggle: 系统标准 Toggle 样式（绿色开/灰色关）
- 分隔线: 0.5px rgba(0,0,0,0.06)，左侧缩进 42px

### 侧边栏 Tab 定义

| Tab | SF Symbol | 内容 |
|-----|-----------|------|
| 总览 | `clock` | 信号仪表盘 + RSSI + 状态 + 校准向导 |
| 设备 | `wifi` (自定义) | 已绑定设备卡片 + 扫描状态 + 可用设备列表 |
| 基础 | `gearshape` | 启用、开机自启 |
| 解锁 | `lock.open` | 靠近时唤醒、唤醒但不解锁、使用屏保 |
| 锁定 | `lock` | 暂停媒体、关闭显示器、延迟锁定、手动锁后不解锁 |
| 网络 | `wifi` | Wi-Fi 暂停、被动模式 |
| 配置 | `folder` | Profile 选择器 + 新建 |

### 各页面详细设计

#### 1. 总览页
- 圆形信号仪表盘（108px），用 conic-gradient 显示信号强度
- RSSI 数值（30px 超细字体）+ dBm 单位
- 状态标签（绿色圆点 + 文字说明）
- "自动校准向导" 按钮（蓝色文字按钮样式）

#### 2. 设备页
- 已绑定设备卡片：绿色圆点 + 设备名 + UUID + "已连接" 状态
- 扫描状态：旋转图标 + "正在扫描附近的 BLE 设备..." 小字提示（非交互，纯展示）
- 可用设备列表：图标 + 设备名 + RSSI + "绑定" 按钮
- 绑定按钮点击后变为"已绑定"并变灰

#### 3. 设置页面（基础/解锁/锁定/网络）
- 标题: 17px 粗体
- 每行: SVG图标(18px) + 标签 + 描述 + Toggle
- 行高: 约 40px，hover 时有浅色背景
- 分隔线: 左侧缩进 42px（对齐文字）

#### 4. 配置页
- Profile Picker: 标签 + 下拉选择器 + "+" 新建按钮
- 保持现有 ProfileManager 逻辑不变

### 交互行为
- 侧边栏点击切换 tab，有高亮状态
- 内容区超出高度时可滚动，侧边栏和设备栏固定
- Toggle 开关切换保持现有 @State 绑定逻辑
- 设备绑定操作保持现有逻辑

## 需要修改的文件

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `MenuDashboardView.swift` | **重写** | 从扁平布局改为侧边栏导航架构 |
| `AppDelegate.swift` | 微调 | popover 宽度改为 440px |

## 不变的部分

- 所有 @State 变量和 @Binding
- 所有 toggle 的 action 逻辑
- FUnManager 调用
- 其他 View 文件（CalibrationWizardView、StatsView 等）
- 设备扫描/绑定逻辑

## 技术要点

1. **NSVisualEffectView**: 用 `.background(.ultraThinMaterial)` 或 `NSVisualEffectView` 包裹实现玻璃效果
2. **侧边栏**: 用 `HStack` + `VStack` 实现，选中状态用 `@State var selectedTab`
3. **SVG → SF Symbols**: 所有图标用 SwiftUI `Image(systemName:)` 替代
4. **滚动**: `ScrollView` 包裹内容区，侧边栏在 `ScrollView` 外部
